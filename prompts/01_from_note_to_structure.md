# Prompt 01 — 메모에서 구조 만들기

아래 메모를 짧은 관찰형 블로그 글의 구조로 바꿔라.

해야 할 일:

1. 메모에서 가장 중요한 변화 하나를 찾는다.
2. 추상적인 주장보다 먼저 보여줄 수 있는 실제 장면을 찾는다.
3. 내용을 3~8개의 번호 문단으로 나눈다.
4. 각 번호마다 `이 문단이 보여줄 장면`과 `이 문단에서 남길 의미`를 한 줄씩 적는다.
5. 아직 완성된 문장을 쓰지 않는다.
6. 메모에 없는 사실은 추가하지 않는다.

출력:

- 중심 생각
- 중심 장면
- 번호별 구조
- 마지막에 남길 문장 후보 2개
