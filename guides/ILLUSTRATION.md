# Illustration Guide

## 역할

삽화는 글을 요약하는 인포그래픽이 아니다.
글에서 가장 중요한 생각이 드러나는 **한 장면**을 만든다.

핵심 원칙:

**개념을 그리지 말고, 개념이 드러나는 행동을 그린다.**

## 장면 선택

다음 순서로 압축한다.

**핵심 의미 -> 행동 -> 가장 단순한 일상 장면**

예:

- 꾸준함 -> 조금씩 반복한다 -> 작은 화분에 물을 조금 주는 사람
- 관점의 차이 -> 서로 다르게 본다 -> 같은 물체를 다른 자세로 보는 두 사람
- 경험 -> 볼 곳을 좁힌다 -> 여러 사물 중 하나만 자세히 보는 사람

뻔한 1차 상징은 피한다.

예:

- 성공 = 트로피
- 성장 = 위로 가는 화살표
- 꾸준함 = 끝없이 달리는 사람

## 하우스 스타일: Note Cartoon

특정 작가나 사이트의 그림체를 복제하지 않는다.
2000년대 한국 웹다이어리와 낙서 카툰에서 느껴지는 단순함만 가져와 독립적인 하우스 스타일로 사용한다.

- 검은색 또는 짙은 회색의 약간 흔들리는 손그림 선
- 지나치게 섬세하지 않은, 조금 굵은 외곽선
- 단순하고 약간 어색한 인물 비례
- 얼굴은 점과 짧은 선 수준으로 최소화
- 감정은 표정보다 자세와 행동으로 표현
- 배경은 흰색, 아주 옅은 회색, 옅은 청회색을 우선
- 필요할 때 한 가지 포인트 색만 사용
- 배경과 사물은 상황 이해에 필요한 만큼만
- 넓은 빈 공간을 허용
- 구도는 매번 장면에 맞게 바꾼다

## 피할 것

- 따뜻한 아이보리 종이 배경을 기본값으로 반복
- `가는 선 + 중앙 아래 작은 인물 + 먼 수평선` 구도의 반복
- 특정 작품의 대표 캐릭터나 고유 구도 복제
- 귀여운 이모티콘형 SD 캐릭터
- 웹툰 컷 분할
- 인포그래픽과 아이콘 배열
- 실사, 반실사, 3D
- 과한 명암, 영화적 조명, 그라데이션
- 그림 속 제목, 문장, 말풍선, 라벨

## 구도

장면에 맞춰 다음 중 하나를 고른다.

- 작은 전신을 화면 한쪽에 배치
- 허리 위 인물을 크게 크롭
- 손과 사물만 표현
- 두 사람이 같은 대상을 다르게 보는 장면
- 인물과 단색 면 하나의 비대칭 구성

중앙 배치는 선택 사항이지 기본값이 아니다.

## Illustration 지시가 없을 때

별도 지시가 없는 것이 기본 상태다.
Agent가 완성된 글에서 가장 강한 장면 하나를 고른다.

Golden Example의 `Illustration`은 스타일 지시가 아니라 **그 글에서 선택된 장면에 대한 선택적 힌트**다.
스타일, 색, 선, 구도 원칙은 항상 이 문서를 따른다.
